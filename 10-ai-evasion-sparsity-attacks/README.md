# Module 10: AI Evasion - Sparsity Attacks

Study notes for the HTB Certified Offensive AI Expert (CAOIE) -- Module 10.

Each file covers a concept with plain English explanations, ASCII diagrams, worked examples, and a security/offensive angle. This module focuses on **sparsity attacks**: crafting adversarial examples that change as *few* features/pixels as possible, in contrast to the "change everything a tiny bit" dense attacks (L2/L-infinity) covered elsewhere in this course.
